# Fashion AI Image Classification

Final Year Dissertation Project comparing Deep Learning and Traditional Machine Learning models for fashion image classification across multiple datasets.

## Overview

This project evaluates the performance of:

* ResNet-18 (Transfer Learning)
* Random Forest
* K-Means Clustering

across multiple fashion-related image datasets including clothing, footwear and jewellery.

## Technologies Used

* Python
* PyTorch
* scikit-learn
* NumPy
* Pandas
* Matplotlib

## Datasets

* Fashion-MNIST
* Fashion Product Images
* Shoes Classification Dataset
* Tanishq Jewellery Dataset

## Key Results

ResNet-18 achieved the strongest overall performance across all datasets, outperforming traditional machine learning approaches in:

* Accuracy
* Precision
* Recall
* Macro F1-score
